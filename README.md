### Deskripsi Program

Program ini dibuat untuk menampilkan data 3 buku yang terdiri dari judul, penulis, dan tahun terbit.

Program dibuat menggunakan dua pendekatan, yaitu:
1. Pemrograman Prosedural.
2. Pemrograman Berorientasi Objek (OOP).

### Daftar File

- `index.php` : Program yang menggabungkan pendekatan pemrograman prosedural dan OOP.
- `README.md` : Dokumentasi program dan penjelasan perbedaan kedua pendekatan.

### 3 Perbedaan yang Saya Rasakan

**1. Cara Penulisan Program**

Pada pemrograman prosedural, kode ditulis berdasarkan urutan langkah dan fungsi. Sedangkan pada OOP, kode disusun menggunakan class dan objek.

**2. Pengelolaan Data**

Pada prosedural, data buku disimpan menggunakan array. Sedangkan pada OOP, data buku dikelola melalui objek yang dibuat dari class Buku.

**3. Pengembangan Program**

Menurut saya, prosedural lebih mudah dipahami untuk program sederhana. Sedangkan OOP lebih terstruktur dan memudahkan pengelolaan program jika nantinya dikembangkan menjadi lebih besar.

### Kesimpulan

Dari percobaan ini, saya memahami bahwa pemrograman prosedural dan OOP memiliki cara kerja yang berbeda. Keduanya dapat digunakan untuk menghasilkan output yang sama, tetapi memiliki struktur kode dan cara pengelolaan data yang berbeda.
